# Tarefa: converter texto de duração em segundos

Crie o arquivo `solucao.py` no diretório de trabalho com a função:

```python
def parse_duracao(texto: str) -> int:
    ...
```

A função recebe uma duração escrita por humanos e retorna o total em **segundos** (`int`).

## Formato aceito

- A duração é formada por 1 a 5 componentes `<inteiro><unidade>`, onde o inteiro é composto
  só por dígitos ASCII `0-9` (zeros à esquerda são permitidos) e a unidade é uma de:
  - `w` = semanas (604800 s), `d` = dias (86400 s), `h` = horas (3600 s), `m` = minutos (60 s),
    `s` = segundos (1 s).
- Unidades aceitas em maiúsculas ou minúsculas (`1H30M` == `1h30m`); nenhum outro caractere é unidade.
- Os componentes devem aparecer na ordem `w`, `d`, `h`, `m`, `s`, cada unidade **no máximo uma vez**
  (componentes podem ser omitidos: `1d5s` é válido).
- Componentes podem estar colados (`1h30m`) ou separados por espaços em branco (`1h 30m`, `1h\t30m`).
  Espaços em branco no início/fim são ignorados. **Não** pode haver espaço entre o número e sua unidade (`1 h` é inválido).
- Não há limite por componente: `90m` == 5400. O inteiro pode ter **qualquer quantidade de dígitos**
  (inclusive milhares de dígitos) e o resultado deve ser exato.

## Erros

- `TypeError` se `texto` não for `str` (subclasses de `str` são aceitas).
- `ValueError` para qualquer entrada fora do formato: string vazia/só espaços, número sem unidade
  (`"90"`), unidade desconhecida (`"5x"`), números negativos ou decimais (`"-5s"`, `"1.5h"`),
  ordem errada (`"30m1h"`), unidade repetida (`"1h2h"`) ou texto extra.

## Desempenho

O tempo deve crescer linearmente com o tamanho da entrada: textos de até ~1 MB compostos basicamente
por espaços em branco (válidos ou inválidos, ex.: `"1d" + " " * 500_000 + "x"`) devem ser processados
em bem menos de 1 segundo.

## Exemplos

| entrada | saída |
|---|---|
| `"45s"` | `45` |
| `"1h30m"` | `5400` |
| `"2d 3h 4m 5s"` | `183845` |
| `"1w 1s"` | `604801` |
| `"  0s  "` | `0` |
| `"1D1S"` | `86401` |

Use apenas a biblioteca padrão (Python 3.11).

+_UNIDADES = {
+    "w": (0, 604800),
+    "d": (1, 86400),
+    "h": (2, 3600),
+    "m": (3, 60),
+    "s": (4, 1),
+}

+def _valor_decimal(texto: str, inicio: int, fim: int) -> int:
+    """Converte os dígitos ASCII do intervalo sem limite de tamanho textual."""
+    valor = 0
+    posicao = inicio
+    while posicao < fim:
+        # Cada conversão abaixo contém no máximo nove dígitos, abaixo do
+        # limite de segurança de conversão decimal de int do Python.
+        proximo = min(posicao + 9, fim)
+        bloco = int(texto[posicao:proximo])
+        tamanho = proximo - posicao
+        valor = valor * (10 ** tamanho) + bloco
+        posicao = proximo
+    return valor
+
+
+def parse_duracao(texto: str) -> int:
+    """Interpreta uma duração como ``1w 2d3h`` e retorna seus segundos."""
+    if not isinstance(texto, str):
+        raise TypeError("texto deve ser uma string")
+
+    tamanho = len(texto)
+    i = 0
+    anterior = -1
+    quantidade = 0
+    total = 0
+
+    while i < tamanho:
+        # Espaços em branco só podem separar componentes ou envolver a duração.
+        while i < tamanho and texto[i].isspace():
+            i += 1
+        if i == tamanho:
+            break
+
+        inicio_digitos = i
+        while i < tamanho and "0" <= texto[i] <= "9":
+            i += 1
+        if i == inicio_digitos:
+            raise ValueError("esperado um número ASCII seguido de uma unidade")
+
+        fim_digitos = i
+        if i == tamanho:
+            raise ValueError("número sem unidade")
+
+        unidade = texto[i]
+        # Comparações explícitas impedem que letras Unicode parecidas sejam aceitas.
+        if "A" <= unidade <= "Z":
+            unidade = chr(ord(unidade) + (ord("a") - ord("A")))
+        info = _UNIDADES.get(unidade)
+        if info is None:
+            raise ValueError("unidade desconhecida")
+
+        ordem, multiplicador = info
+        if ordem <= anterior:
+            raise ValueError("unidades fora de ordem ou repetidas")
+
+        valor = _valor_decimal(texto, inicio_digitos, fim_digitos)
+        total += valor * multiplicador
+        anterior = ordem
+        quantidade += 1
+        i += 1
+
+        # Próximo caractere deve iniciar outro componente ou ser espaço.
+        if i < tamanho and not texto[i].isspace() and not ("0" <= texto[i] <= "9"):
+            raise ValueError("texto extra após componente")
+
+    if quantidade == 0:
+        raise ValueError("duração vazia")
+    return total
