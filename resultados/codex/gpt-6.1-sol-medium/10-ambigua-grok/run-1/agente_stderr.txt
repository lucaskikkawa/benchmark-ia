# Tarefa: classificar uma mensagem curta

Crie dois arquivos no diretório de trabalho:

- `solucao.py` com `classificar_mensagem(texto: str) -> dict`
- `SUPOSICOES.md` em UTF-8, com as decisões que você tomar nos pontos abertos

Só a biblioteca padrão. A função é pura: o mesmo texto sempre devolve o mesmo dict, sem ler arquivo, relógio ou rede.

## O que está fechado

O dict tem **pelo menos** estas chaves (pode ter outras):

```python
{
    "categoria": str,
    "urgente": bool,
    "tamanho": int,
}
```

- `tamanho` é `len(texto)`, em code points, **sem** `strip`, sem normalizar (NFC, NFD, NFKC) e sem contar bytes UTF-8. `"ação"` tem tamanho 4. `"🙂"` tem tamanho 1. `"a\u0301"` tem tamanho 2. `"\ud800"` tem tamanho 1 e não pode levantar erro. Quebra de linha, `\u00a0` e `\u200b` contam.
- `urgente` é `True` exatamente quando a substring `"URGENTE"` aparece em `texto` (maiúsculas, sem exigir palavra inteira, sem casefold e sem normalizar antes). `"urgente"`, `"Urgente"` e `"URGEN"` são `False`. `"XURGENTEY"` e `" URGENTE"` são `True`. Um lookalike cirílico (`"URGENT\u0415"`, com `Е`) é `False`. `"URGENTE"` no fim de um texto de 100_000 caracteres continua `True`, e `tamanho` é 100_000 mais o que vier junto.
- `texto == ""` (string vazia, e só ela) devolve `categoria == "vazia"`, `urgente is False` e `tamanho == 0`.
- Qualquer outro texto, inclusive só espaços, `"vazia"`, `"\u00a0"` ou `"\n"`, tem `categoria` string não vazia e **diferente** de `"vazia"`.
- Se `texto` não for `str` (`None`, `bytes`, `bytearray`, `int`), levante `TypeError`. Não codifique o texto para decidir isso.

Os testes automáticos cobrem só este núcleo.

+# Decisões de classificação
+
+- As categorias são `vazia`, `pergunta` e `outro`.
+- Apenas a string exatamente vazia recebe `vazia`, com prioridade sobre as demais regras.
+- Qualquer texto contendo o sinal ASCII `?` recebe `pergunta`, independentemente de palavras ou da posição do sinal. Sinais semelhantes, como `？`, não disparam essa regra.
+- Todo texto não vazio sem `?` recebe `outro`. Isso inclui espaços, quebras de linha, pontuação isolada, caracteres invisíveis e a palavra literal `vazia`.
+- Nenhuma palavra dispara categorias. Maiúsculas e acentos não influenciam a categoria, pois a única busca é pelo sinal `?`; não se aplica normalização, remoção de acentos, `strip` ou conversão de caixa.
+- A urgência é independente da categoria: somente a substring literal `URGENTE` ativa o campo `urgente`, respeitando maiúsculas e os caracteres originais.
+- O tamanho é calculado diretamente com `len(texto)`, incluindo caracteres combinantes e substitutos Unicode isolados, sem codificação em bytes.
+- O dict contém somente `categoria`, `urgente` e `tamanho`, sem campos extras. Instâncias de `str`, inclusive subclasses, são aceitas; outros tipos levantam `TypeError`.

+"""Classificação determinística de mensagens curtas, sem dependências externas."""
+
+
+def classificar_mensagem(texto: str) -> dict:
+    """Classifica pelo sinal de pergunta, preservando o texto nas demais regras.
+
+    Levanta TypeError quando o argumento não é uma string.
+    """
+    if not isinstance(texto, str):
+        raise TypeError("texto deve ser str")
+
+    if texto == "":
+        categoria = "vazia"
+    elif "?" in texto:
+        categoria = "pergunta"
+    else:
+        categoria = "outro"
+
+    return {
+        "categoria": categoria,
+        "urgente": "URGENTE" in texto,
+        "tamanho": len(texto),
+    }
