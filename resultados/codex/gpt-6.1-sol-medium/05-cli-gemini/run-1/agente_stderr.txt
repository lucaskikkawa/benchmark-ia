# 05 - Ferramenta CLI de Contagem e Métricas de Texto

Implemente uma ferramenta de linha de comando no arquivo `contatexto.py` na raiz do seu diretório de trabalho.

## Invocação

```bash
python contatexto.py [ARQUIVO] [FLAGS]
```

A CLI deve utilizar a biblioteca padrão `argparse`.

## Argumentos e Flags

- `ARQUIVO` (posicional, obrigatório): caminho para o arquivo de texto UTF-8 a ser analisado.
- `-l`, `--linhas` (flag booleana): contabiliza a quantidade de linhas no arquivo (utilizando quebras de linha/`splitlines()`).
- `-p`, `--palavras` (flag booleana): contabiliza o total de palavras (tokens separados por espaços em branco via `split()`).
- `-c`, `--chars` (flag booleana): contabiliza o total de caracteres no arquivo (`len(conteudo)`).
- `--top N` (inteiro >= 1): lista as `N` palavras mais frequentes.
  - Para o top palavras, tokens são convertidos para minúsculas e caracteres de pontuação nas pontas (`.,!?;:"'()[]{}`) são removidos via `.strip(...)`. Tokens vazios resultantes são descartados.
  - Em caso de empate de frequência, ordene as palavras alfabeticamente.
- `--json` (flag booleana): formata o resultado como um objeto JSON.
- `-o`, `--saida CAMINHO` (string): grava a saída no caminho especificado em vez de imprimir o resultado na stdout. Quando esta flag for utilizada, a CLI deve escrever o resultado no arquivo e imprimir na stdout exatamente: `Salvo em CAMINHO\n`. Caso as pastas pai do arquivo de saída não existam, crie-as automaticamente.

### Regras de Exibição das Métricas
1. Se **nenhuma** das flags de métrica (`-l`, `-p`, `-c`, `--top`) for fornecida, a ferramenta deve exibir **linhas, palavras e caracteres** por padrão.
2. Se **ao menos uma** flag de métrica for informada, ela deve exibir **estritamente** as métricas selecionadas.

### Formato de Saída em Texto (padrão)
Cada métrica selecionada é exibida em uma linha:
```
Linhas: 10
Palavras: 50
Caracteres: 320
Top Palavras:
  - python: 6
  - codigo: 4
```

### Formato de Saída em JSON (`--json`)
Um objeto JSON indentado (`indent=2`, `ensure_ascii=False`) contendo apenas as chaves das métricas selecionadas:
- `"linhas"`: int
- `"palavras"`: int
- `"caracteres"`: int
- `"top_palavras"`: lista de objetos `{"palavra": str, "ocorrencias": int}`

### Códigos de Saída (Exit Codes)
- `0`: Operação concluída com sucesso.
- `1`: Erro operacional (ex.: arquivo não existe, caminho aponta para um diretório em vez de arquivo regular, ou erro de leitura / decodificação). Deve exibir mensagem de erro na `stderr` iniciando com `Erro` (por exemplo, `Erro: ...` ou `Erro ao ler arquivo: ...`) e terminar com código 1.
- `2`: Erro de sintaxe nos argumentos (ex.: arquivo ausente, flag inexistente, ou `--top` com valor menor que 1).

+"""Ferramenta de linha de comando para contar e analisar texto UTF-8."""
+
+import argparse
+from collections import Counter
+import json
+from pathlib import Path
+import sys
+
+
+PONTUACAO = ".,!?;:\"'()[]{}"
+
+
+def inteiro_positivo(valor):
+    """Valida o limite de palavras usando os erros de sintaxe do argparse."""
+    try:
+        numero = int(valor)
+    except ValueError:
+        raise argparse.ArgumentTypeError("deve ser um inteiro >= 1") from None
+    if numero < 1:
+        raise argparse.ArgumentTypeError("deve ser um inteiro >= 1")
+    return numero
+
+
+def analisar(conteudo, args):
+    resultado = {}
+    padrao = not (args.linhas or args.palavras or args.chars or args.top)
+    if padrao or args.linhas:
+        resultado["linhas"] = len(conteudo.splitlines())
+    if padrao or args.palavras:
+        resultado["palavras"] = len(conteudo.split())
+    if padrao or args.chars:
+        resultado["caracteres"] = len(conteudo)
+    if args.top is not None:
+        tokens = (token.lower().strip(PONTUACAO) for token in conteudo.split())
+        frequencias = Counter(token for token in tokens if token)
+        ordenadas = sorted(frequencias.items(), key=lambda item: (-item[1], item[0]))
+        resultado["top_palavras"] = [
+            {"palavra": palavra, "ocorrencias": ocorrencias}
+            for palavra, ocorrencias in ordenadas[:args.top]
+        ]
+    return resultado
+
+
+def formatar(resultado, usar_json):
+    if usar_json:
+        return json.dumps(resultado, indent=2, ensure_ascii=False)
+    rotulos = {"linhas": "Linhas", "palavras": "Palavras", "caracteres": "Caracteres"}
+    linhas = []
+    for metrica, valor in resultado.items():
+        if metrica == "top_palavras":
+            linhas.append("Top Palavras:")
+            linhas.extend(
+                f"  - {item['palavra']}: {item['ocorrencias']}" for item in valor
+            )
+        else:
+            linhas.append(f"{rotulos[metrica]}: {valor}")
+    return "\n".join(linhas)
+
+
+def main(argv=None):
+    parser = argparse.ArgumentParser(description=__doc__)
+    parser.add_argument("arquivo", metavar="ARQUIVO", help="arquivo de texto UTF-8")
+    parser.add_argument("-l", "--linhas", action="store_true", help="contar linhas")
+    parser.add_argument("-p", "--palavras", action="store_true", help="contar palavras")
+    parser.add_argument("-c", "--chars", action="store_true", help="contar caracteres")
+    parser.add_argument("--top", type=inteiro_positivo, metavar="N", help="listar as N palavras mais frequentes")
+    parser.add_argument("--json", action="store_true", help="formatar como JSON")
+    parser.add_argument("-o", "--saida", metavar="CAMINHO", help="salvar resultado em arquivo")
+    args = parser.parse_args(argv)
+
+    try:
+        entrada = Path(args.arquivo)
+        if not entrada.is_file():
+            raise OSError(f"'{args.arquivo}' não é um arquivo regular existente")
+        with entrada.open("r", encoding="utf-8", newline="") as arquivo:
+            conteudo = arquivo.read()
+        saida = formatar(analisar(conteudo, args), args.json) + "\n"
+        if args.saida is not None:
+            destino = Path(args.saida)
+            destino.parent.mkdir(parents=True, exist_ok=True)
+            with destino.open("w", encoding="utf-8", newline="") as arquivo:
+                arquivo.write(saida)
+            print(f"Salvo em {args.saida}")
+        else:
+            sys.stdout.write(saida)
+    except (OSError, UnicodeError, ValueError) as erro:
+        print(f"Erro: {erro}", file=sys.stderr)
+        return 1
+    return 0
+
+
+if __name__ == "__main__":
+    sys.exit(main())
