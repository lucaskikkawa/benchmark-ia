# Tarefa: CLI de agenda pessoal

Crie `agenda_cli.py` no diretório de trabalho. Ele é o programa completo: `argparse`, subcomandos, arquivo JSON e códigos de saída. Só a biblioteca padrão. Os testes chamam o script com `subprocess`.

```text
python agenda_cli.py adicionar --titulo TEXTO --prioridade baixa|media|alta [--prazo YYYY-MM-DD] --arquivo CAMINHO
python agenda_cli.py listar --arquivo CAMINHO [--prioridade baixa|media|alta] [--somente-abertas]
python agenda_cli.py concluir --id N --arquivo CAMINHO
```

`--arquivo` é obrigatório em todos. Sem subcomando, argumento desconhecido ou escolha inválida de prioridade: o `argparse` encerra com código 2.

## Arquivo JSON

Se `adicionar` receber um caminho que não existe, crie o arquivo. `listar` e `concluir` num caminho que não existe: código 2, stderr exatamente `erro: arquivo inexistente\n`, stdout vazio.

Formato (UTF-8, `indent=2`, `ensure_ascii=False`, quebra de linha final):

```json
{
  "proximo_id": 1,
  "tarefas": [
    {
      "id": 1,
      "titulo": "Comprar leite",
      "prioridade": "alta",
      "prazo": null,
      "concluida": false
    }
  ]
}
```

Na leitura, qualquer JSON que não siga esse formato gera `erro: arquivo invalido` (código 2). Exija:

- objeto com exatamente as chaves `proximo_id` e `tarefas`;
- `proximo_id` inteiro ≥ 1 (`bool` não vale; `1.0` também não) e **maior** que todo `id` já usado (se não houver tarefas, só ≥ 1). Buracos são válidos: ids `1` e `3` com `proximo_id` `5` podem ser listados. O próximo `adicionar` grava id `5`, não `4` e não `max+1`;
- `tarefas` é uma lista de objetos com exatamente `id`, `titulo`, `prioridade`, `prazo`, `concluida`;
- `id` inteiro ≥ 1, único, não `bool`;
- `titulo` string não vazia depois das regras abaixo, sem `\n`, `\r` ou `\t`, e sem espaço nas pontas (o arquivo já deve estar normalizado; título `"  a  "` ou `"\n"` é inválido);
- `prioridade` é `baixa`, `media` ou `alta`;
- `prazo` é `null` ou `YYYY-MM-DD` de um dia real no calendário gregoriano de `datetime.date` (anos 1 a 9999). `2000-02-29` existe; `1900-02-29` e `2100-02-29` não;
- `concluida` é bool (`0` e `1` não valem).
- `id` duplicado, chave a mais ou chave a menos torna o arquivo inválido.

## adicionar

- `--titulo` é obrigatório. Vale o texto depois de `str.strip` (isso inclui espaços Unicode, como `\u00a0`). Se ficar vazio: `erro: titulo vazio`.
- `adicionar` em arquivo que já existe e é inválido: `erro: arquivo invalido`, e o arquivo **permanece byte a byte** como estava.
- `listar` não reescreve o arquivo.
- Se o título (já sem espaços das pontas) contiver `\n`, `\r` ou `\t`: `erro: titulo invalido`.
- `--prioridade` obrigatória, uma das três opções.
- `--prazo` opcional. Se vier, tem de ser uma data real `YYYY-MM-DD`; senão `erro: prazo invalido`. Ausente grava `null`.
- O id novo é o `proximo_id` atual. Depois grave `proximo_id` incrementado em 1 e `concluida` false.
- Sucesso: stdout exatamente `ok id=N\n`, stderr vazio, código 0. Nada além disso.

## listar

Imprima uma tarefa por linha, sem cabeçalho, separador tab (`\t`), nesta ordem de colunas:

```text
id	prioridade	estado	prazo	titulo
```

- `estado` é `aberta` ou `concluida`.
- `prazo` nulo vira `-`.
- Ordem: prioridade `alta`, depois `media`, depois `baixa`; dentro da mesma prioridade, `id` crescente.
- `--prioridade` filtra uma prioridade. `--somente-abertas` tira as concluídas. Os dois filtros juntos são um E.
- Nenhuma tarefa (ou nenhuma após o filtro): stdout vazio (zero bytes), código 0.
- Cada linha impressa termina com `\n`.

## concluir

- `--id` inteiro (`01` é o id `1`). Se não existir: `erro: id inexistente`.
- Se já estiver concluída: `erro: ja concluida`.
- Senão marque `concluida` true, grave o arquivo e imprima `ok id=N\n` com código 0.

- `titulo vazio`
- `titulo invalido`
- `prazo invalido`
- `arquivo inexistente`
- `arquivo invalido`
- `id inexistente`
- `ja concluida`

+import argparse
+import datetime
+import json
+import re
+import sys
+from pathlib import Path
+
+
+PRIORIDADES = ("baixa", "media", "alta")
+ORDEM_PRIORIDADE = {"alta": 0, "media": 1, "baixa": 2}
+CHAVES_TAREFA = {"id", "titulo", "prioridade", "prazo", "concluida"}
+
+
+class ErroAgenda(Exception):
+    """Erro de regra apresentado sem traceback."""
+
+
+def prazo_valido(prazo):
+    if not isinstance(prazo, str):
+        return False
+    if re.fullmatch(r"[0-9]{4}-[0-9]{2}-[0-9]{2}", prazo) is None:
+        return False
+    try:
+        datetime.date.fromisoformat(prazo)
+    except ValueError:
+        return False
+    return True
+
+
+def titulo_valido(titulo):
+    return (
+        isinstance(titulo, str)
+        and bool(titulo)
+        and titulo == titulo.strip()
+        and not any(caractere in titulo for caractere in "\n\r\t")
+    )
+
+
+def validar_agenda(agenda):
+    if not isinstance(agenda, dict) or set(agenda) != {"proximo_id", "tarefas"}:
+        return False
+    proximo_id = agenda["proximo_id"]
+    if type(proximo_id) is not int or proximo_id < 1:
+        return False
+    if not isinstance(agenda["tarefas"], list):
+        return False
+
+    ids = set()
+    for tarefa in agenda["tarefas"]:
+        if not isinstance(tarefa, dict) or set(tarefa) != CHAVES_TAREFA:
+            return False
+        identificador = tarefa["id"]
+        if (
+            type(identificador) is not int
+            or identificador < 1
+            or identificador >= proximo_id
+            or identificador in ids
+        ):
+            return False
+        ids.add(identificador)
+        if not titulo_valido(tarefa["titulo"]):
+            return False
+        if tarefa["prioridade"] not in PRIORIDADES:
+            return False
+        if tarefa["prazo"] is not None and not prazo_valido(tarefa["prazo"]):
+            return False
+        if type(tarefa["concluida"]) is not bool:
+            return False
+    return True
+
+
+def objeto_sem_duplicatas(pares):
+    objeto = {}
+    for chave, valor in pares:
+        if chave in objeto:
+            raise ValueError("chave duplicada")
+        objeto[chave] = valor
+    return objeto
+
+
+def carregar(caminho, criar=False):
+    try:
+        with caminho.open("r", encoding="utf-8") as arquivo:
+            agenda = json.load(arquivo, object_pairs_hook=objeto_sem_duplicatas)
+    except FileNotFoundError:
+        if criar:

+        raise ErroAgenda("arquivo inexistente") from None
+    except (OSError, UnicodeError, ValueError, RecursionError):
+        raise ErroAgenda("arquivo invalido") from None
+    if not validar_agenda(agenda):
+        raise ErroAgenda("arquivo invalido")
+    return agenda
+
+
+def salvar(caminho, agenda):
+    try:
+        with caminho.open("w", encoding="utf-8", newline="\n") as arquivo:
+            json.dump(agenda, arquivo, indent=2, ensure_ascii=False)
+            arquivo.write("\n")
+    except (OSError, UnicodeError):
+        raise ErroAgenda("arquivo invalido") from None
+
+
+def adicionar(args, caminho, agenda):
+    titulo = args.titulo.strip()
+    if not titulo:
+        raise ErroAgenda("titulo vazio")
+    if not titulo_valido(titulo):
+        raise ErroAgenda("titulo invalido")
+    if args.prazo is not None and not prazo_valido(args.prazo):
+        raise ErroAgenda("prazo invalido")
+
+    identificador = agenda["proximo_id"]
+    agenda["tarefas"].append(

+            "titulo": titulo,
+            "prioridade": args.prioridade,
+            "prazo": args.prazo,
+            "concluida": False,
+        }
+    )
+    agenda["proximo_id"] += 1
+    salvar(caminho, agenda)
+    print(f"ok id={identificador}")
+
+
+def listar(args, agenda):
+    tarefas = sorted(

+    )
+    for tarefa in tarefas:

+        estado = "concluida" if tarefa["concluida"] else "aberta"
+        prazo = tarefa["prazo"] if tarefa["prazo"] is not None else "-"
+        print(
+            f"{tarefa['id']}\t{tarefa['prioridade']}\t{estado}\t"
+            f"{prazo}\t{tarefa['titulo']}"
+        )
+
+
+def concluir(args, caminho, agenda):

+        if tarefa["id"] == args.id:
+            if tarefa["concluida"]:

+            tarefa["concluida"] = True
+            salvar(caminho, agenda)
+            print(f"ok id={tarefa['id']}")
+            return
+    raise ErroAgenda("id inexistente")
+
+
+def criar_parser():
+    parser = argparse.ArgumentParser(description=__doc__)
+    subcomandos = parser.add_subparsers(dest="comando", required=True)
+
+    parser_adicionar = subcomandos.add_parser("adicionar")
+    parser_adicionar.add_argument("--titulo", required=True)
+    parser_adicionar.add_argument("--prioridade", choices=PRIORIDADES, required=True)
+    parser_adicionar.add_argument("--prazo")
+
+    parser_listar = subcomandos.add_parser("listar")
+    parser_listar.add_argument("--prioridade", choices=PRIORIDADES)
+    parser_listar.add_argument("--somente-abertas", action="store_true")
+
+    parser_concluir = subcomandos.add_parser("concluir")
+    parser_concluir.add_argument("--id", type=int, required=True)
+
+    for subparser in (parser_adicionar, parser_listar, parser_concluir):
+        subparser.add_argument("--arquivo", required=True)
+    return parser
+
+
+def main(argv=None):
+    args = criar_parser().parse_args(argv)
+    caminho = Path(args.arquivo)
+    try:
+        agenda = carregar(caminho, criar=args.comando == "adicionar")
+        if args.comando == "adicionar":
+            adicionar(args, caminho, agenda)
+        elif args.comando == "listar":
+            listar(args, agenda)
+        else:
+            concluir(args, caminho, agenda)
+    except ErroAgenda as erro:
+        print(f"erro: {erro}", file=sys.stderr)
+        return 2
+    return 0
+
+
+if __name__ == "__main__":
+    sys.exit(main())
