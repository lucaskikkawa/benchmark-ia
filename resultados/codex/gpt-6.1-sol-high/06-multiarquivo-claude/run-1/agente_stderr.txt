`Livro` valida os campos ao ser criado (`__post_init__`): `isbn`, `titulo` e `autor` devem ser `str`

## `acervo.py` — `class Acervo`

- `adicionar(livro: Livro) -> None` — `TypeError` se não for `Livro`; `ValueError` se já existir livro
  com o mesmo `isbn`.
- `obter(isbn: str) -> Livro` — `LivroNaoEncontrado` se não existir.
- `buscar_por_autor(trecho: str) -> list[Livro]` — livros cujo `autor` contém `trecho`, sem diferenciar
  maiúsculas/minúsculas (compare com `str.casefold()`; `"STRAUSS"` encontra `"Strauß"`), ordenados por
  `titulo` e depois `isbn` (comparação simples de `str`, sem locale). Trecho vazio encontra todos.
- `__len__()` — quantidade de livros; `__contains__(isbn)` — `isbn in acervo`.

## `emprestimos.py` — `class ServicoEmprestimos`

```python
ServicoEmprestimos(acervo: Acervo, limite_por_usuario: int = 3, prazo_dias: int = 14,
                   multa_diaria: float = 1.0, max_renovacoes: int = 2)
```

- `ValueError` no construtor se `limite_por_usuario < 1`, `prazo_dias < 1`, `multa_diaria < 0`
  ou `max_renovacoes < 0`.

- `emprestar(isbn: str, usuario: str, data: datetime.date) -> Emprestimo`
  - `LivroNaoEncontrado` se o isbn não está no acervo;
  - `LivroIndisponivel` se o livro já está emprestado;
  - `LimiteEmprestimos` se o usuário já tem `limite_por_usuario` empréstimos ativos;
  - (verificações nesta ordem) `data_prevista = data + prazo_dias`.
  - O serviço usa o **mesmo** objeto `Acervo` recebido: livros adicionados ao acervo depois da criação
    do serviço podem ser emprestados.
- `devolver(isbn: str, data: datetime.date) -> float` — encerra o empréstimo e retorna a multa:
  `dias_de_atraso * multa_diaria` (atraso = dias após `data_prevista`; devolver até a data prevista → `0.0`),
  arredondada a 2 casas.
  - `LivroNaoEncontrado` se o isbn não está no acervo; `EmprestimoNaoEncontrado` se não está emprestado;
  - `ValueError` se `data` for anterior a `data_emprestimo` (o empréstimo continua ativo).
- `disponivel(isbn: str) -> bool` — `LivroNaoEncontrado` se o isbn não está no acervo.
- `emprestimos_de(usuario: str) -> list[Emprestimo]` — ativos do usuário, ordenados por `data_prevista` e depois `isbn`.
- `renovar(isbn: str, data: datetime.date) -> Emprestimo` — substitui o empréstimo ativo por um novo com
  `renovacoes + 1` e `data_prevista = max(data_prevista atual, data + prazo_dias)` (os demais campos não
  mudam) e o retorna. Verificações nesta ordem:
  - `LivroNaoEncontrado` se o isbn não está no acervo; `EmprestimoNaoEncontrado` se não está emprestado;
  - `ValueError` se `data` for anterior a `data_emprestimo`;
  - `RenovacaoNegada` se o empréstimo está atrasado (`data > data_prevista`) ou se já foi renovado
    `max_renovacoes` vezes. Em qualquer erro o empréstimo continua como estava.
- `atrasados(data: datetime.date) -> list[Emprestimo]` — empréstimos ativos (de todos os usuários) com
  `data_prevista < data`, ordenados por `data_prevista` e depois `isbn`.
- `devolver` usa a `data_prevista` vigente (após renovações).

+from .modelos import Livro, LivroNaoEncontrado
+
+
+class Acervo:
+    def __init__(self) -> None:
+        self._livros: dict[str, Livro] = {}
+
+    def adicionar(self, livro: Livro) -> None:
+        if not isinstance(livro, Livro):
+            raise TypeError("livro deve ser Livro")
+        if livro.isbn in self._livros:
+            raise ValueError(f"ISBN já cadastrado: {livro.isbn}")
+        self._livros[livro.isbn] = livro
+
+    def obter(self, isbn: str) -> Livro:
+        try:
+            return self._livros[isbn]
+        except KeyError:
+            raise LivroNaoEncontrado(isbn) from None
+
+    def buscar_por_autor(self, trecho: str) -> list[Livro]:
+        trecho = trecho.casefold()
+        return sorted(
+            (livro for livro in self._livros.values() if trecho in livro.autor.casefold()),
+            key=lambda livro: (livro.titulo, livro.isbn),
+        )
+
+    def __len__(self) -> int:
+        return len(self._livros)
+
+    def __contains__(self, isbn: str) -> bool:
+        return isbn in self._livros

+"""Empréstimos, devoluções e renovações de livros do acervo."""

+from dataclasses import replace
+from datetime import date, timedelta
+
+from .acervo import Acervo
+from .modelos import (

+    EmprestimoNaoEncontrado,
+    LimiteEmprestimos,
+    LivroIndisponivel,
+    RenovacaoNegada,

+class ServicoEmprestimos:
+    def __init__(
+        self,
+        acervo: Acervo,
+        limite_por_usuario: int = 3,
+        prazo_dias: int = 14,
+        multa_diaria: float = 1.0,
+        max_renovacoes: int = 2,
+    ) -> None:
+        if limite_por_usuario < 1:
+            raise ValueError("limite_por_usuario deve ser pelo menos 1")
+        if prazo_dias < 1:
+            raise ValueError("prazo_dias deve ser pelo menos 1")
+        if multa_diaria < 0:
+            raise ValueError("multa_diaria não pode ser negativa")
+        if max_renovacoes < 0:
+            raise ValueError("max_renovacoes não pode ser negativo")
+        self._acervo = acervo
+        self._limite_por_usuario = limite_por_usuario
+        self._prazo = timedelta(days=prazo_dias)
+        self._multa_diaria = multa_diaria
+        self._max_renovacoes = max_renovacoes
+        self._ativos: dict[str, Emprestimo] = {}
+
+    def emprestar(self, isbn: str, usuario: str, data: date) -> Emprestimo:
+        self._acervo.obter(isbn)
+        if isbn in self._ativos:
+            raise LivroIndisponivel(isbn)
+        quantidade = sum(emp.usuario == usuario for emp in self._ativos.values())
+        if quantidade >= self._limite_por_usuario:
+            raise LimiteEmprestimos(usuario)
+        emprestimo = Emprestimo(isbn, usuario, data, data + self._prazo)
+        self._ativos[isbn] = emprestimo
+        return emprestimo
+
+    def _obter_emprestimo(self, isbn: str) -> Emprestimo:
+        self._acervo.obter(isbn)
+        try:
+            return self._ativos[isbn]
+        except KeyError:
+            raise EmprestimoNaoEncontrado(isbn) from None
+
+    def devolver(self, isbn: str, data: date) -> float:
+        emprestimo = self._obter_emprestimo(isbn)
+        if data < emprestimo.data_emprestimo:
+            raise ValueError("devolução anterior ao empréstimo")
+        dias_de_atraso = max(0, (data - emprestimo.data_prevista).days)
+        multa = round(float(dias_de_atraso * self._multa_diaria), 2)
+        del self._ativos[isbn]
+        return multa
+
+    def disponivel(self, isbn: str) -> bool:
+        self._acervo.obter(isbn)
+        return isbn not in self._ativos
+
+    def emprestimos_de(self, usuario: str) -> list[Emprestimo]:
+        return sorted(
+            (emp for emp in self._ativos.values() if emp.usuario == usuario),
+            key=lambda emp: (emp.data_prevista, emp.isbn),
+        )
+
+    def renovar(self, isbn: str, data: date) -> Emprestimo:
+        emprestimo = self._obter_emprestimo(isbn)
+        if data < emprestimo.data_emprestimo:
+            raise ValueError("renovação anterior ao empréstimo")
+        if (
+            data > emprestimo.data_prevista
+            or emprestimo.renovacoes >= self._max_renovacoes
+        ):
+            raise RenovacaoNegada(isbn)
+        renovado = replace(
+            emprestimo,
+            renovacoes=emprestimo.renovacoes + 1,
+            data_prevista=max(emprestimo.data_prevista, data + self._prazo),
+        )
+        self._ativos[isbn] = renovado
+        return renovado
+
+    def atrasados(self, data: date) -> list[Emprestimo]:
+        return sorted(
+            (emp for emp in self._ativos.values() if emp.data_prevista < data),
+            key=lambda emp: (emp.data_prevista, emp.isbn),
+        )
