## O que está fechado

O dict tem **pelo menos** estas chaves (pode ter outras):

```python
{
    "categoria": str,
    "urgente": bool,
    "tamanho": int,
}
```

- `tamanho` é `len(texto)`, em code points, **sem** `strip`, sem normalizar (NFC, NFD, NFKC) e sem contar bytes UTF-8. `"ação"` tem tamanho 4. `"🙂"` tem tamanho 1. `"a\u0301"` tem tamanho 2. `"\ud800"` tem tamanho 1 e não pode levantar erro. Quebra de linha, `\u00a0` e `\u200b` contam.
- `urgente` é `True` exatamente quando a substring `"URGENTE"` aparece em `texto` (maiúsculas, sem exigir palavra inteira, sem casefold e sem normalizar antes). `"urgente"`, `"Urgente"` e `"URGEN"` são `False`. `"XURGENTEY"` e `" URGENTE"` são `True`. Um lookalike cirílico (`"URGENT\u0415"`, com `Е`) é `False`. `"URGENTE"` no fim de um texto de 100_000 caracteres continua `True`, e `tamanho` é 100_000 mais o que vier junto.
- `texto == ""` (string vazia, e só ela) devolve `categoria == "vazia"`, `urgente is False` e `tamanho == 0`.
- Qualquer outro texto, inclusive só espaços, `"vazia"`, `"\u00a0"` ou `"\n"`, tem `categoria` string não vazia e **diferente** de `"vazia"`.
- Se `texto` não for `str` (`None`, `bytes`, `bytearray`, `int`), levante `TypeError`. Não codifique o texto para decidir isso.

Os testes automáticos cobrem só este núcleo.

+# Decisões de classificação
+
+- As categorias são `vazia`, `reclamacao`, `duvida`, `pedido`, `elogio` e `outro`. Somente a string exatamente vazia recebe `vazia`.
+- Para escolher a categoria, aplica-se `casefold`, decomposição Unicode NFD e remoção dos caracteres de categoria Unicode `Mn` (marcas não espaçadoras). Assim, maiúsculas e acentos usuais não distinguem palavras-chave. Essa transformação ocorre apenas numa cópia usada para classificar.
+- Uma palavra é uma sequência máxima reconhecida pela expressão regular Unicode `[^\W\d_]+`: caracteres de palavra, exceto dígitos decimais e sublinhado. As palavras-chave precisam coincidir com uma dessas sequências inteiras; não basta aparecerem dentro de outra palavra.
+- `reclamacao`: palavras `ruim`, `pessimo`, `problema`, `defeito` ou `reclamacao`.
+- `duvida`: presença literal do sinal ASCII `?`, ou palavras `duvida`, `como`, `qual`, `quando`, `onde` ou `porque`.
+- `pedido`: palavras `preciso`, `solicito`, `gostaria` ou `ajuda`.
+- `elogio`: palavras `obrigado`, `obrigada`, `otimo`, `excelente` ou `parabens`.
+- Havendo múltiplas correspondências, a prioridade é `reclamacao`, depois `duvida`, depois `pedido`, depois `elogio`. Não há inferência de contexto, negação ou ironia.
+- Qualquer texto não vazio sem correspondência recebe `outro`, inclusive espaços, quebras de linha, pontuação sem `?`, caracteres invisíveis e a palavra `vazia`. Pontuação que contenha `?` recebe `duvida`.
+- O resultado tem exatamente os três campos solicitados, sem campos extras. `tamanho` é sempre `len(texto)` original e `urgente` é sempre o resultado de `"URGENTE" in texto`, sem nenhuma transformação ou limite de busca.
+- São aceitas instâncias de `str`, inclusive subclasses; qualquer outro tipo levanta `TypeError`. Não se faz codificação em bytes, leitura de arquivos, consulta de relógio ou acesso à rede.

+"""Classificação determinística de mensagens, usando só a biblioteca padrão."""
+
+import re
+import unicodedata
+
+
+def classificar_mensagem(texto: str) -> dict:
+    """Retorna categoria, urgência literal e tamanho original da mensagem.
+
+    As regras de categoria e sua prioridade estão em SUPOSICOES.md.
+    Entradas que não sejam strings levantam TypeError.
+    """
+    if not isinstance(texto, str):
+        raise TypeError("texto deve ser uma str")
+
+    tamanho = len(texto)
+    urgente = "URGENTE" in texto
+
+    if texto == "":
+        categoria = "vazia"
+    else:
+        simplificado = "".join(
+            caractere
+            for caractere in unicodedata.normalize("NFD", texto.casefold())
+            if unicodedata.category(caractere) != "Mn"
+        )
+        palavras = set(re.findall(r"[^\W\d_]+", simplificado))
+
+        if palavras & {"ruim", "pessimo", "problema", "defeito", "reclamacao"}:
+            categoria = "reclamacao"
+        elif "?" in texto or palavras & {
+            "duvida", "como", "qual", "quando", "onde", "porque"
+        }:
+            categoria = "duvida"
+        elif palavras & {"preciso", "solicito", "gostaria", "ajuda"}:
+            categoria = "pedido"
+        elif palavras & {"obrigado", "obrigada", "otimo", "excelente", "parabens"}:
+            categoria = "elogio"
+        else:
+            categoria = "outro"
+
+    return {"categoria": categoria, "urgente": urgente, "tamanho": tamanho}
